Using it from GitHub Desktop (Windows)

  1. In GitHub Desktop, switch to the branch compare/gpt-vs-claude and click Fetch / Pull origin.
  2. Choose Repository → Show in Explorer.
  3. Double-click START_HERE.html (this page). It opens in your browser straight from disk: no server, no install, no internet needed.
  4. Open the 3D comparison viewer, search or pick an object, then drag to rotate (both views move together unless you untick Link cameras), scroll to zoom, Shift-drag to pan.

All model data the viewer needs is in viewer/data/ (generated from the .vox files by tools/compare/build_compare.py), so it works from file://. Coverage report: docs/COMPARISON_COVERAGE.md.
